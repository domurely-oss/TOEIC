TOEIC 免登入公開教材頁簽（2026-11-17）

上傳方式
1. 先備份 GitHub TOEIC 儲存庫原有的 index.html。
2. 將本壓縮檔的 index.html、guest.js、guest.css、guest-catalog.js 上傳到原 index.html 所在位置。
3. 只覆蓋 index.html；其他原有檔案請保留。等待 GitHub Pages 完成部署後按 Ctrl+F5。
4. 網址後加 #guest 可直接進入免登入頁簽。
本更新包尚未直接部署到您的 GitHub 網站。

新增內容
- 獨立「免登入使用」頁簽；原有 JavaScript、登入、分類、筆記、逐字稿上傳流程保留。
- 已加入公開資料夾根目錄的快速清單：207 個音檔、18 個文字檔。
- 同名 mp3 與 .en.txt / .zh.txt 自動配對；沒有對應文字時顯示提示。
- 可自行選擇英文、中文文字檔；支援貼入其他公開檔案連結。
- 音檔與文字由 Google Drive 官方預覽直接顯示，免 API 金鑰、免訪客授權。
- 訪客頁不修改原教材、筆記、分類，也不向 Drive 寫入。

清單與內容更新的差別
- 檔案內容由 Drive 即時預覽，重新選取教材會重載預覽。
- 快速配對清單是 2026-11-17 取得的根目錄檔名與 ID，不會自動同步新增、改名、刪除。
- 「瀏覽最新資料夾」直接顯示目前清單，包含子資料夾；子資料夾內容不列入快速配對清單。
- 更新快速清單：Windows PowerShell 切到本資料夾，執行 .\update-catalog.ps1，成功後只須上傳 guest-catalog.js。
  此指令碼不需安裝 Python 或外部套件；依據 Google 公開資料夾 HTML 擷取，Google 更改格式時可能需調整。
  若電腦政策禁止執行腳本，請由網站管理人員在允許的環境執行，不需變更執行政策。

使用限制
- 資料夾與個別檔案必須允許「知道連結的任何人」檢視；本更新不變更共用權限。
- 訪客頁使用官方預覽，不提供原播放器的 A–B 循環、變速、自動下一首、編輯或雲端上傳。
- TXT 已實測中英文可同時匿名預覽；SRT/VTT 是否可預覽依 Google 支援情況，不能保證。
- Google 預覽錯誤、檔案權限或網路限制時，使用「另開檔案」檢查。
- 不含音檔及逐字稿副本；讀取時須連網。

驗證
- 已於未登入網站的瀏覽器中確認 01_Day1 英文、中文 TXT 同時顯示。
- 已保留原頁面所有既有內嵌 JavaScript 原文；新增功能使用獨立檔案。
- GitHub 正式部署及原帳號登入後的寫入操作尚未實測。
