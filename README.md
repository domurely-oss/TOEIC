# TOEIC 英文辨識後自動翻譯繁體中文版

基於「逐字稿 Google Drive 儲存修正版」更新，保留既有的播放器、獨立教材清單、Google Drive 登入／同步／手動儲存、單曲重複、A–B 重複、Whisper 語音辨識等功能。

## 新增功能

1. 「英文辨識完成後自動翻譯成繁體中文」預設啟用，可取消勾選；設定保存在瀏覽器。
2. Whisper 成功產出英文逐字稿後，先保留英文，再使用瀏覽器端翻譯模型，將中文顯示於「中文翻譯」欄位並儲存於瀏覽器。
3. 「🌐 重新翻譯成中文」可於手動修改英文逐字稿後重譯；已有中文內容時會詢問是否覆蓋。自動翻譯則不會覆蓋先前的中文筆記／譯文。
4. 翻譯模型為 `Xenova/opus-mt-en-zh`，使用 `@xenova/transformers@2.17.2`；翻譯結果透過 OpenCC.js 轉換為臺灣繁體中文。第一次使用需要連網下載模型及轉換程式，下載大小與速度視模型資源和裝置而定。翻譯在瀏覽器本機執行，不使用需輸入密鑰的付費翻譯 API。
5. 若勾選既有「辨識完成後自動儲存至 Google Drive」，英文辨識與中文翻譯流程結束後會嘗試一起上傳 `.en.txt`、`.zh.txt`；若有同名雲端檔案會為防止覆寫而保留在本機，需按「☁ 儲存逐字稿至 Google Drive」確認。
6. 若翻譯失敗，英文辨識結果仍保留，可稍後再翻譯。若 OpenCC 載入失敗，中文翻譯可能包含簡體字，介面會提醒。

## 部署

解壓 ZIP，將 `index.html` 覆蓋 GitHub Pages 原檔，再以 Ctrl+F5 重新整理。
請確認瀏覽器可以存取 jsDelivr 與 Hugging Face 模型檔案。音檔太長時翻譯耗時較久，請保持分頁開啟。機器翻譯可能不準確，尤其是 TOEIC 專有名詞，請自行核對。

## 重要安全說明

此版本繼承前版的 Google Drive 完整讀寫 OAuth scope，權限不只限於教材資料夾。請只在可信任的自有網站使用。上傳需要實際 Google 授權，且需取得資料夾編輯權限。

## 測試範圍

已執行 HTML／JavaScript 靜態檢查、ZIP 完整性檢查；無法在目前離線測試環境確認外部模型下載、瀏覽器翻譯的品質及實際 Google Drive 寫入，需部署後實測。


## 20 分鐘音檔辨識支援

- 英文語音辨識的單次音檔長度限制由 600 秒提升至 1200 秒（20 分鐘）。
- 超過 20 分鐘時將顯示對應提醒。
- 長音檔會增加瀏覽器記憶體與運算需求；若記憶體不足，建議拆分音檔。
