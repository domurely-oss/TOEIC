# TOEIC 左側教材清單＋右側播放器與逐字稿版

## 更新方式
將 `index.html` 覆蓋 GitHub Pages 專案首頁後，按 Ctrl + F5 重新整理。

## 本版更新
- 桌面版：左側為固定教材清單（可獨立捲動），右側上方為播放器，下方為中英文逐字稿與筆記。
- 左側優先呈現教材搜尋、題型篩選、教材列表。Google Drive 登入／同步與新增教材可點擊「⚙ Google Drive 同步與新增教材」展開。
- 選取左側教材直接更新右側內容，不需切換頁面。
- 窄螢幕（850px 以下）：依序顯示教材清單、播放器、逐字稿，以避免左右擠壓。
- 保留上一版 20 分鐘音檔辨識上限、英文轉繁體中文、Google Drive 儲存、單曲重複、播放速度及其他功能。

## 注意事項
20 分鐘語音辨識會佔用較多記憶體。Google Drive 授權及雲端寫入需在實際部署後測試。
