# TOEIC 多筆勾選批次分類版

以「分類 Google Drive 跨裝置同步版」為基礎。

## 新功能
- 左側教材列表每筆新增勾選框；點勾選框不會播放教材。
- 「全選目前顯示」只勾選符合目前搜尋、題型、分類篩選的教材。
- 可以跨篩選條件保留勾選；顯示已選總筆數，並可清除選取。
- 從下拉選單選取自訂分類或「未分類」，按「套用分類」批次修改。
- 修改結果先存入本機，需按「管理我的分類 > 儲存分類至 Drive」上傳供其他裝置讀取。
- Google Drive 分類設定只同步 Drive API 雲端音檔的歸類；本機音檔或分享連結教材的分類不會跨裝置同步。

## 安裝
將 index.html 替換 GitHub Pages 專案同名檔案，按 Ctrl+F5 重新整理。

## 驗證
JavaScript 語法可用 node --check；實際 Google Drive 授權與同步需要在部署環境實測。
